# HARNESS AI AGENTIC - Storyboard & Video AI Generator (JSB12 KHKT)

Dự án cuộc thi KHKT khóa JSB12 - Xây dựng ứng dụng AI Agentic tạo kịch bản và storyboard chuỗi hình ảnh/video bằng Python (FastAPI + LangGraph) và Frontend (HTML/CSS/JS).

## Cấu trúc dự án
- `backend/`: FastAPI Backend với LangGraph Multi-Agent Orchestration.
- `frontend/`: Giao diện Web hiển thị Storyboard, Lịch sử Chat & Gallery cộng đồng.
